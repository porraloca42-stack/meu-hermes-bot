# TikTok script doctor

1. Confirm project, target viewer, objective, product/claim constraints and requested duration.
2. Generate a small number of meaningfully different concepts, then recommend one.
3. Make the opening immediately legible and curiosity-driven; do not use deceptive hooks.
4. Build a coherent progression: hook, identification/problem, useful insight or demonstration, payoff and CTA.
5. Design visual changes to support meaning, not as empty stimulation. Match every scene to narration and on-screen text.
6. Provide production-ready assets: timing, spoken line, on-screen copy, visual direction, motion/edit, sound guidance, caption and CTA as appropriate.
7. For the user's faceless format, do not assume the user will appear on camera.
8. Avoid unsupported health, financial, scientific, product-performance or guaranteed-result claims.
9. Critique the script for clarity, pacing, originality, plausibility, policy risks and conversion friction before delivery.
